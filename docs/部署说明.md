# 另一台设备部署说明

## 环境要求

| 软件 | 版本 | 用途 |
|---|---|---|
| JDK | 17（必须是 17+，Spring Boot 3 不兼容 JDK 8） | 后端 |
| Node.js | 18+（建议 20/22） | 前端 |
| MySQL | 8.0 | 数据库 |
| Maven | 3.8+（或用 IDEA 自带） | 后端构建 |

## 一、导入数据库（已有全部数据，无需再跑迁移脚本）

方式一（命令行）：
```bash
mysql -uroot -p < sql/bil_mall_full_20260917.sql
```
方式二（Navicat/Workbench）：直接运行该 sql 文件。

会自动建库 `bil_mall` 并导入全部数据（6 个商户、41 件商品、订单、轮播图等）。
> 若你的 MySQL 密码不是 123456，改 `springboot/src/main/resources/application.yml`
> 里的 `password`，或设环境变量 `MYSQL_PASSWORD`。

## 二、启动后端（端口 9999）

双击 `start-backend.bat`，或手动：
```bash
cd code-scaffold/code-scaffold/springboot
set JAVA_HOME=C:\Program Files\Java\jdk-17
mvn -DskipTests package
java -jar target\springboot-0.0.1-SNAPSHOT.jar
```

## 三、启动前端（端口 8080）

```bash
cd code-scaffold/code-scaffold/vue
npm install        # 首次必跑，装 node_modules
npm run serve
```

## 常见问题

- **启动报 JDK 版本错**：确认用的是 JDK 17（`java -version`）
- **前端编译报错**：删掉 `vue/node_modules` 重新 `npm install`
- **git 推送**：仓库已关联 https://github.com/zbbkl/ecommerce-mall
